各层来源与口径限制

数据层表用途口径限制
内容层 weibo.post / weibo.comment 原文、证据流、预测输入 评论是采样集合，不代表全量评论分布
情绪层 dashboard.sentiment_prediction 六分类预测、置信度、BERT 对照 查询必须按 model_version 过滤
热度层 weibo.post_engagement_ts 点赞 / 评论 / 转发快照 快照稀疏，不是连续时间序列
话题层 weibo.topic / weibo.post_topic 话题聚合、详情页 仅代表显式携带话题的帖子
传播层 weibo.post_discovery hot / keyword / kol / retweet 入口 一帖可多入口，不能 count(*) 当帖子数
账号层 weibo.user 认证、画像 tier、KOL 解释 followers_count 仅 profile_tier ≥ 1 可信

使用提醒

解读注意事项

  • 评论数据为采样集合，不代表平台全量评论分布。
  • 互动数来自 post_engagement_ts 平台快照，不是实时计数。
  • profile_tier = 0 用户画像字段（粉丝数等）不可信，仅 tier ≥ 1 可用作排序信号。
  • 风险分（risk_score）服务于排序与解释，不是绝对真值。
  • BERT 对照仅作模型解释 / 困难样本发现，不是主展示模型；分歧样本见总览页 → 双模型分歧分析。
