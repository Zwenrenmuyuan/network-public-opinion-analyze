# 六分类情感标注规范

本文档用于 LLM 预标注和人工复核。目标是稳定六分类边界，不把边界样本随意压成三分类。

## 标签定义

| 标签 | 判定重点 | 常见表达 |
|---|---|---|
| 积极 | 支持、喜欢、开心、期待、赞赏、庆幸 | 好棒、喜欢、支持、开心、期待、万幸 |
| 愤怒 | 抱怨、责骂、攻击、不满、烦躁、强烈反对 | 烦死、垃圾、气死、讨厌、凭什么、无语死了 |
| 悲伤 | 难过、失落、无助、遗憾、疲惫、崩溃但不指向攻击对象 | 难受、想哭、崩溃、心累、失望、没办法 |
| 恐惧 | 害怕、担心、危险、惊慌、后怕、风险感 | 好怕、吓死、担心、后怕、危险、紧张 |
| 惊讶 | 意外、震惊、没想到、反常、猎奇、不可思议 | 没想到、震惊、居然、神了、离谱、惊呆 |
| 中性 | 事实陈述、转述新闻、说明信息，无明显个人情绪 | 发布、报道、显示、数据、通知、发生 |

## 边界规则

- 愤怒 vs 悲伤：有明确责备、攻击对象、强烈不满时标 `愤怒`；以难过、无力、失落、痛苦为主时标 `悲伤`。
- 恐惧 vs 惊讶：强调危险、担心、后怕、害怕时标 `恐惧`；强调没想到、反常、震惊但没有安全威胁时标 `惊讶`。
- 积极 vs 中性：只有事实陈述或新闻转述时标 `中性`；出现赞赏、支持、喜欢、庆幸、期待时标 `积极`。
- 愤怒 vs 惊讶：如果“离谱/震惊”后面伴随责骂或强烈反对，标 `愤怒`；只是意外发现，标 `惊讶`。
- 悲伤 vs 恐惧：对已经发生的损失、失落标 `悲伤`；对可能发生的风险、危险、未知后果标 `恐惧`。
- 多情绪文本选主导情绪；无法判断主导时给 `needs_human_review=true`。

## LLM 输出

LLM 只做预标注，不直接作为最终真值。必须返回单个 JSON 对象：

```json
{
  "label": "悲伤",
  "second_label": "愤怒",
  "confidence": 0.72,
  "reason": "表达焦虑和无力为主，虽有抱怨但攻击性不强。",
  "needs_human_review": true
}
```

字段要求：

- `label` 必须是 `积极|愤怒|悲伤|恐惧|惊讶|中性` 之一。
- `second_label` 填最可能混淆的第二标签；没有明显第二标签时填空字符串。
- `confidence` 是 0 到 1 的数值，不要用百分号。
- `reason` 用一句中文说明主导情绪依据。
- `needs_human_review` 在边界模糊、讽刺反语、信息不足、top1/top2 接近时为 `true`。

## 复核优先级

- 优先复核 `愤怒/悲伤`、`恐惧/惊讶`、`积极/中性` 边界样本。
- 优先复核 `confidence < 0.75` 的样本。
- 优先复核 LLM 与当前模型预测或原标签不一致的样本。
- 优先复核 `恐惧`、`惊讶` 小类样本，避免小类被系统性吞掉。
- 不复核的 LLM 高置信样本只能进入 silver set；人工确认后才进入 gold set。

## 数据边界

- 原始 SMP 文件不改，修复结果另存映射或派生 parquet。
- `virus` 数据只保留疫情专项参考，不参与主线通用模型修复。
- 爬虫数据只作为离线业务样本来源，本项目消费导出的 Parquet，不接入爬虫运行时。
